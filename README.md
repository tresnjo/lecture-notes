# Integration Theory — Lecture Notes

**Read the notes online: <https://tresnjo.github.io/intgtheory/>**

My own notes from the course TMV101 / MMA110 Integration Theory, taught by Jeffrey Steif at Gothenburg University in autumn 2026, and heavily based on his lecture notes. They cover measure theory, the Lebesgue integral, convergence theorems, signed measures and differentiation.

The book is written in [Quarto](https://quarto.org). Every push to `main` rebuilds the site automatically through GitHub Actions and publishes it to the `gh-pages` branch.
