12  The 3× Covering Lemma

We now start a new chapter which will study differentiation in \(\mathbb R^n\).

ImportantTheorem 12.1 — Simple theorem

Let \(f: [0,1] \rightarrow \mathbb R\) be monotone, then for a.e. \(x\), \(f\) is differentiable with a finite derivative.

ImportantTheorem 12.2 — The fundamental theorem of calculus

First fundamental theorem of calculus: if \(f\) is a continous function on \([a,b]\)d \[F(x) = \int_a^x f(t) dt\] then \[F'(x) = x \forall x.\] Second fundamental theorem of calculus: If \(f\) is a continuously differentiable function on \([a,b]\) then \[\int_a^b f'(x) dx = f(b) - f(a)\]

We first discuss the first fundamental theorem, and argue that it cannot possibly hold for all measurable bounded functions. If \(f\) is continuous function and \(g\) any measurable function which agrees with \(f\) a.e., then we have \[\int_a^x f(t) dt = \int_a^x g(t) dt\]for every \(x\), hence for every \(x\) we have \[ \left( \int_a^x g(t) dt\right)'(x) = f(x)\] and therefore \[ \left( \int_a^x g(t) dt\right)'(x) = g(x)\]will fail at every point where \(f(x) \neq g(x)\). However, we do have \[ \left( \int_a^x g(t) dt\right)'(x) = g(x) \ \mathrm{a.e.}\]So the most we can hope for a bounded measurable \(f\) is that the first fundamental theorem holds at a.e. \(x\). We will show this and generalize it to higher dimensions, which we will be called Lebesgue’s differentiation theorem.

Note that continuous functions are also measurable. To see this, take \(U \subseteq \mathbb R\) then \[f^{-1}(U)\]must be open by continuity. And since open sets in \([a,b]\) are Borel sets. Since the Borel algebra is generated by all open sets of the real line, we have that the preimage of any Borel set is also in \(\mathcal B_{[a,b]}\) so \(f\) is measurable. But not every measurable function is continuous.

Approximations by sets and by continuous functions

The Borel \(\sigma\)-algebra on \(\mathbb R^n\), denoted by \(\mathcal B^n\) can be described as generated by open sets in \(\mathbb R^n\) or as the product \(\sigma\)-algebra coming from \((\mathbb R, \mathcal B)\).

ImportantTheorem 12.3
  1. For any Borel set \(E \subseteq \mathbb R^n\) we have \[m(E) = \sup\{ m(K) : K \subseteq E, K \mathrm{compact}\}\]
  2. If \(f\in L^1(\mathbb R^n, \mathcal B^n, m)\) and \(\epsilon > 0\), then there exists a continuous function \(g\) on \(\mathbb R^n\) so that \[\int_{\mathbb R^n} |f(x) - g(x)| dm(x) < \epsilon\]

Theorem 12.3(i) is sometimes referred to as approximation from within by compact sets.

We will also need to approximate sets with respect to other measures.

NoteDefinition 12.4 — Regular

A Borel measure \(\nu\) on \(\mathbb R^n\) is regular if \(\nu(K) < \infty\) for all compact sets \(K \subseteq \mathbb R^n\).

An example of a regular Borel measure is the Lebesgue measure. An example of a non-regular Borel measure is the counting measure.

ImportantTheorem 12.5 — Approximating from outside using open sets

Let \(\nu\) be a regular Borel measure on \(\mathbb R^n\). If \(E\) is a Borel set then \[\nu(E) = \mathrm{inf}\{\nu(O) : E \subseteq O, O \ \mathrm{open}\}\]

Since the Lebesgue measure is also regular, it satisfies both outer regularity and inner regularity, meaning the measure can be approximated from the outside using open sets or from the inside using compact sets.

Since the counting measure is not regular, it fails the above theorem. Take for example \(E = \{0\}\), then \(\nu(E) = 1\). But any open set containing \(0\) contains an interval \((-\epsilon, \epsilon)\), thus \(\nu(O) = \infty\). Note however that for inner regularity, we can simply take \(K = \{0\}\) which is compact (single points are compact), so the supremum is achieved.

A covering lemma

ImportantTheorem 12.6 — A simple covering lemma

Let \(A_1,...,A_k\) be open balls in \(\mathbb R^2\). There is a subset \(B_1,...,B_l\) of these which are disjoint and that satisfy \[\sum_{j=1}^l m(B_j) \geq \frac{m(\bigcup_{i=1}^k A_i)}{9}\]

NoteProof

Let \(B_1\) be the largest of \(A_1,...,A_k\). Remove all remaining \(A_i\)’s which intersect \(B_1\). Let \(B_2\) be the largest of the remaining \(A_i\)’s. Remove all remaining \(A_i\)’s which intersect \(B_2\). Let \(B_3\) be largest of remaining … and continue until no \(A_j\)’s are left. This produces \(B_1, ..., B_l\) which are disjoint by construction. \(\square\)

Claim If \(A_i\) is NOT in the final list, then for some \(j\) we have \[A_i \subseteq B_j^\star\] where \(^\star\) denotes the ball concentric with \(B_j\) but three times the radius. Since \(A_i\) was not chosen, it must have intersected one of the \(B_j\)’s. The first \(B_j\) it intersects must be as large as \(A_i\) since otherwise we would have chosen \(A_i\) instead. We must therefore have \[r(A_i) \leq r(B_j)\] and since they intersect, we have \[d(\mathrm{center}(A_i), \mathrm{center}(B_j)) < r(A_i) + r(B_j)\]Thus for any point \(x\in A_i\) we have \[d(x, \mathrm{center}(B_j)) \leq d(x, \mathrm{center}(A_i)) + d(\mathrm{center}(A_i), \mathrm{center}(B_j)) < 2r(A_i) + r(B_j) < 3r(B_j)\] You can think of this as three contributions depending on

In the case where \(A_i\) was selected, then \(A_i = B_j\) for some j, then \(B_j \subseteq B_j^\star\) trivially. But if it was eliminated, we had that \(A_i \subseteq B_j^\star\), so every \(A_i\) is contained in some \(B_j^\star\), meaning \[\bigcup_i A_i \subseteq \bigcup_j B_j^\star\]

We thus obtain, by applying monotonicity and countable subadditivity \[m(\bigcup_{i=1}^k A_i) \leq m(\bigcup_{j=1}^l B_j^\star) \leq \sum_{j=1}^l m(B_j^\star) = 9 \sum_{j=1}^l m(B_j)\] as desired.

ImportantTheorem 12.7 — A covering lemma

Let \(\mathcal C\) be a collection of open balls in \(\mathbb R^n\) with \(U\) being their union. \(\forall c < m(U)\), there exists \(B_1, B_2,..., B_k \in \mathcal C\) which are disjoint satisfying \[\sum_{i=1}^k m(B_i) \geq \frac{c}{3^n}\]

Before constructing the proof, we notice two differences between this covering lemma and the simpler covering lemma. First of all, there is no assumption about the collection \(\mathcal C\) being finite. The conclusion is about \(c\) and not \(m(U)\) too.

Since \(c < m(U)\), by Theorem 12.3(i) we can choose \(K \subseteq U\) compact s.t. \(m(K) > c\). A compact set has finite subcover, meaning we can take \(A_1,...,A_m \in \mathcal C\) that cover \(K\). Now we repeat the same steps as before, choosing \(B_1\) being among those of maximal size, then choose \(B_2\) among these to have maximal size but disjoint from \(B_1\), and repeating. The claim is identical as before, meaning if \(A_i\) is NOT in the final list, then for some \(j\) we have \[A_i \subseteq B_j^\star\] where \(^\star\) denotes the ball concentric with \(B_j\) but three times the radius. Since \(A_i\) was not chosen, it must have intersected one of the \(B_j\)’s. Unlike before however, the measure is bounded by a factor of \(3^n\) instead. \[c < m(K) < m(\bigcup_{j=1}^k B_j^\star) \leq \sum_{j=1}^k m(B_j^\star) = 3^n \sum_{j=1}^k m(B_j)\] as desired.
