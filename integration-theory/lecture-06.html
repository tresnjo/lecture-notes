6  Introducing the Lebesgue Integral and Modes of Convergence

Simple function approximation. If \((X,\mathcal M)\) is a measurable space and \(f:X\to[0,\infty]\) is measurable, then there exists a sequence \((\phi_n)\) of simple functions with \(0\le\phi_1\le\phi_2\le\cdots\) such that \(\phi_n\to f\) pointwise, and uniformly on any set where \(f\) is bounded. Construction. For each \(n\), chop \([0,2^n)\) into \(2^n\cdot2^n=2^{2n}\) pieces of width \(\tfrac1{2^n}\) each, and round \(f(x)\) down to the left endpoint of whichever piece it lands in (capping at \(2^n\) once \(f(x)\) gets that large):\[ \phi_n(x):=\sum_{k=0}^{2^{2n}-1}\frac{k}{2^n}\,\mathbf 1_{\left\{x:f(x)\in\left[\frac{k}{2^n},\frac{k+1}{2^n}\right)\right\}}\ +\ 2^n\,\mathbf 1_{\{x:f(x)\ge2^n\}}.\] That is: replace \(f(x)\) by \(f\big(\tfrac{k}{2^n}\big)\) where \(\tfrac{k}{2^n}\) is the closest grid point to \(f(x)\) from below, i.e. \(\tfrac{k}{2^n}\le f(x)\). Each \(\phi_n\) is simple: the sets \(\big\{x:f(x)\in[\tfrac{k}{2^n},\tfrac{k+1}{2^n})\big\}\) (\(k=0,\dots,2^{2n}-1\)) and \(\{x:f(x)\ge2^n\}\) are disjoint, measurable (preimages of Borel sets under the measurable \(f\)), and cover \(X\) (since \(f\ge0\)). Monotonicity, \(\phi_n\le\phi_{n+1}\). Going from resolution \(n\) to \(n+1\), every grid interval of width \(\tfrac1{2^n}\) splits into two of width \(\tfrac1{2^{n+1}}\), and rounding down onto a finer grid can only land on an equal-or-larger value than rounding down onto the coarser one; the cap also rises, from \(2^n\) to \(2^{n+1}\). So \(\phi_n(x)\le\phi_{n+1}(x)\) for every \(x\). Pointwise convergence. Fix \(x\). If \(f(x)<\infty\), then once \(2^n>f(x)\), \(\phi_n(x)\) sits within \(\tfrac1{2^n}\) of \(f(x)\) (that’s the grid width), so \(\phi_n(x)\to f(x)\). If \(f(x)=\infty\), then \(\phi_n(x)=2^n\to\infty=f(x)\) for every \(n\). Uniform convergence on bounded sets. If \(f\le M\) on some set \(S\), then for every \(n\) with \(2^n>M\), every \(x\in S\) satisfies \(f(x)<2^n\), so \(\phi_n(x)\) is within \(\tfrac1{2^n}\) of \(f(x)\) — a bound depending only on \(n\), not on \(x\). Hence \(\phi_n\to f\) uniformly on \(S\).

The Lebesgue integral and convergence theorems

Before we proceed, we consider the class of nonnegative measurable functions \[L^+((X, \mathcal M, m)) = \{f: X\rightarrow [0,\infty], \text{f is measurable}\}\]

NoteDefinition 6.1 — The Lebesgue integral for nonnegative simple functions

Let \(\phi(x)\) be a simple function in \(L^+((X, \mathcal M, m))\) \[\phi(x) = \sum_{i=1}^n c_i I_{E_i}\]with \(c_i \geq 0 \forall i\). The integral is then defined \[\int \phi(x) dm(x) = \sum_{i=1}^n c_i m(E_I)\]

NoteDefinition 6.2 — Integral of nonnegative simple function over specified region

If \(\phi\) is a simple function in \(L^+((X, \mathcal M, m))\) and \(A \in \mathcal M\) we define \[\int_A \phi(x) dm(x) = \int \phi(x) \mathbb I_A dm(x)\] where we note that the integrand on the RHS is a simple function and hence the integral is defined.

ImportantProposition 6.3 — Four properties which hold for the integral of nonnegative simple functions

Let \(\phi, \psi\) be simple nonnegative functions, then the following holds. (a) \(\int c\phi(x) dm(x) = c\int \phi(x) dm(x)\) \(\forall c \geq 0\). (b) \(\int (\phi(x) + \psi(x)) dm(x) = \int \phi(x) dm(x) + \int \psi(x) dm(x)\). (c)\(\phi \leq \psi\) implies that \(\int \phi(x) dm(x) \leq \int \psi(x) dm(x)\) (d) The mapping from \(\mathcal M\) to \([0,\infty]\) given by \(A\rightarrow \int_A \phi(x) dm(x)\) is a measure on \(\mathcal M\).

Note that \[\int (\phi(x) - \psi(x) ) dm(x) = \int \phi(x) dm(x) - \int \psi(x) dm(x)\]iff at least one of the integrals on the RHS is defined. This is different from property (b) in Proposition 6.3 since in this case, we are integrating nonnegative functions which may lead to a \(\infty - \infty\) situation which is not necessarily defined (whereas \(\infty + \infty\) is).

We are now ready to define the integral for all functions in \(L^+((X, \mathcal M, m))\). We will use the idea that we can approximate a measurable function by simple functions.

NoteDefinition 6.4 — The integral for nonnegative measurable functions

If \(f \in L^+((X, \mathcal M, m))\) we define \[\int f(x) dm(x) = \sup\{ \int \phi(x) dm(x): 0 \leq \phi \leq f, \phi \ \mathrm{simple}\}\]which can certainly become infinity.

One might attempt to also define the Lebesgue integral as follows \[\int f(x) dm(x) = \inf\{ \int \phi(x) dm(x): \phi \geq f, \phi \ \mathrm{simple}\}\]

This agrees with Definition 6.4 when \(f\) is bounded and vanishes outside a set of finite measure. The reason is that an infimum can be rewritten as a supremum: if \(0 \leq f < M\), set \(g(x) := M - f(x)\). Then \(\phi \geq f\) exactly when \(M - \phi \leq g\), so taking the infimum over simple functions above \(f\) is the same as taking the supremum over simple functions below \(g\).

For unbounded functions, however, the two definitions differ. Take \(f(x) = x^{-1/2}\) on \((0,1)\). A simple function takes only finitely many values, while \(f\) takes arbitrarily large values near \(0\). So a simple function \(\phi \geq f\) must take the value \(+\infty\) on a set of positive measure near \(0\) (see this Stack Exchange discussion). Every such \(\phi\) therefore has \(\int \phi\, dm = \infty\), and the infimum definition gives \(\int f\, dm = \infty\). The supremum definition instead gives the correct value \[\int_0^1 x^{-1/2}\, dm(x) = 2,\] since simple functions below \(f\) never need to be infinite. This is why the Lebesgue integral is defined through the supremum. Figure 6.2 shows both approaches for \(x^{-1/2}\).

It can be straightforwardly verified that properties (a)-(c) from Proposition 6.3 are also satisfied for nonnegative measurable functions as defined above. In particular, we will prove property (c) in what follows.

Convergence theorems

In what follows, we discuss three important convergence theorems which answer the question on when the limit and the integral operations commute. The first two, the monotone and dominated Lebesgue convergence theorem, tells us that it is possible to do so under certain restrictions on the sequence of measurable functions.

ImportantTheorem 6.5 — Monotone convergence theorem

Given a measure space, let \((f_n)\) be a sequence of functions in \(L^+((X, \mathcal M, m))\) satisfying \[0 \leq f_1 \leq f_2 \leq ...\] for every x and define \(f\) by \[f(x) := \lim_{n\rightarrow \infty} f_n(x) = \sup_n f_n(x)\] then \[\int f dm = \lim_{n\rightarrow \infty} \int f_n dm\]

NoteProof

To prove the \(\geq\) we first realize that \(\int f_n dm\) is increasing and hence a limit. For the same reason \(\int f dm \geq \int f_n dm\) for every \(n\) we also have \(\int f_dm \geq \lim \int f_n dm\). To prove the reverse inequality, we first start by the definition of \(\int f dm\) which is that for every simple function \(\phi \leq f\) we have \[\int \phi dm \leq \lim_{n\rightarrow \infty} \int f_n dm\]. Now fix the simple function and let \(\alpha < 1\) and define \(E_n := \{x: f_n(x) \geq \alpha \phi(x)\}\) and observe that \(E_1 \subseteq E_2...\) from the fact that \(f_n(x)\) is increasing, and \(X = \bigcup_n E_n\). For every \(n\) we now have \[\int f_n dm \geq \int f_n 1_{E_n} dm \geq \alpha \phi 1_{E_n} dm = \alpha \int_{E_n} \phi dm\] and let \(n\rightarrow \infty\) and use that for a fixed nonnegative simple function \(A\rightarrow \int_A \phi dm\) is a measure, now we have an increasing sequence of sets for which we evaluate this measure whose union is \(X\), using continuity from below of meaures, we have that \(\lim_{n\rightarrow \infty} \int f_n dm \geq \alpha \int \phi dm\) which holds for all \(\alpha < 1\). \(\square\)

We now discuss three additional examples for when the MCT can be applied, and whether additional assumptions need to be imposed.

Two immediate corollaries of the MCT are now stated.

ImportantCorollary 6.6 — Linearity of Lebesgue integral for nonnegative measurable functions

If \(f_1\) and \(f_2\) in \(L^+((X, \mathcal M, m))\) then \[\int (f_1+f_2)dm = \int f_1 dm + \int f_2 dm\]

NoteProof

Choose \(\phi_n\) and \(\psi_n\) to be increasing simple functions to \(f_1\) and \(f_2\), then \(\phi_n + \psi_n\) is a sequence of simple functions increasing towards \(f_1+f_2\)

where in the middle step we used the linearity over simple functions, and the MCT in the outer most equalities. \(\square\)

ImportantCorollary 6.7 — Exchanging infinite sum and Lebesgue integral

If \(f_1, f_2,...\) in \(L^+((X, \mathcal M, m))\) then \[\int (\sum_{i=1}^\infty f_i) dm = \sum_{i=1}^\infty (\int f_i dm)\]

NoteProof

By the corollary above, we have for every \(N\) that \[\int (\sum_{i=1}^N f_i) dm = \sum_{i=1}^N (\int f_i dm)\]where we want to let \(N\rightarrow \infty\), the RHS goes to \(\sum_{i=1}^\infty (\int f_i dm)\) while the LHS goes to \(\int (\sum_{i=1}^\infty f_i)\) by the MCT. Note that \(g_N := (\sum_{i=1}^N f_i)\) defines a sequence of increasing nonnegative measurable functions (since sum of measurable functions is measurable), and whose pointwise limit is precisely \((\sum_{i=1}^\infty f_i)\) (which is also measurable by Proposition 5.6 from Lecture 5 for which we can thus apply the MCT. \(\square\)

ImportantProposition 6.8 — Lebesgue integral zero for nonnegative measurable functions equivalence

If \(f\in L^+((X, \mathcal M ,m))\) then \[\int fdm = 0\] iff \(f=0\) a.e. The proof is provided in the lecture notes. We remind ourselves that the measurable functions taken into consideration are positive, i.e. \(f\rightarrow [0,\infty]\).

Note that the above proposition also implies that if \(f = h-g\) then \(h=g\) almost everywhere, that is to say, they are equivalent modulo the nullset \[m(\{x \in X : h(x) \neq g(x)\}) =0\]

ImportantTheorem 6.9 — Fatou’s lemma

If \((f_n)\) is a sequence of functions in \(L^+((X, \mathcal M, m))\) then \[\int \liminf_{n\rightarrow \infty} f_n dm \leq \liminf_{n\rightarrow \infty} \int f_n dm\]

Fatou’s lemma is the best we can do with minimal assumptions about \(f_n\).

Remember from Lecture 5 we showed that if \((f_n)\) is a sequence of measurable functions, then \(\liminf f_n\) is measurable also.

We now relax the assumption that the range of the measurable functions is restricted to the positive reals, and define the integral for general measurable functions.

NoteDefinition 6.10 — Lebesgue integral for general measurable functions

Definition of integral for general measurable functions. if \(f:(X,\mathcal M, m)\rightarrow \overline{\mathbb R}\), then we define \[\int f(x) dm(x) := \int f^+(x) dm(x) - \int f^{-}(x) dm(x)\] provided that at least one of the two terms on the RHS is finite (this way, we avoid any \(\infty - \infty\) scenario.) Note that \(f^-, f^+ \in L^+\) which makes them well-defined.

We are now ready to state what it means for a function to be Lebesgue integrable.

NoteDefinition 6.11 — Lebesgue integrable

If \(f\) is a measurable function on \((X, \mathcal M, m)\) and \(\int f dm\) is defined and finite, we say that \(f\) is Lebesgue integrable. Or tantamountly, having \(\int |f| dm\) being finite.

Why are these equivalent statements? Notice that \(f = f^+ - f^-\) and \(|f| = f^+ + f^-\) where \(f^\pm = \max(\pm f, 0)\), the Lebesgue integral is then defined above. However, if that is to be finite, then we demand both \(\int f^\pm dm\) to be finite, but that is equivalent to demanding \(\int |f| dm = \int f^+ dm + \int f^- dm\) to be finite.

Before proceeding, we introduce some useful notation. Let \[L^1((X, \mathcal M, m)) := \{f: (X,\mathcal M, m)\rightarrow \overline{\mathbb R} : \int | f| dm < \infty\}\]which in words read: the set of all real-valued measurable functions on the measure space s.t. the integral of the absolute value of \(f\) wrt to the measure \(m\) is finite. If a function is Lebesgue integrable, it is thus an element of \(L^1\) (I will occasionally drop the argument for \(L^1\)). You can think of the elements as equivalence classes of measurable functions modulo any nullsets.

Remember that the Lebesgue integral for a general measurable function \(f\in L^1\) can be decomposed into \[f = f^+ - f^-\]with both \(f^\pm\) non-negative and measurable and thus in \(L^+\). Then define \[\int f dm = \int f^+ dm - \int f^- dm\]which is finite since \(f\in L^1\) means \[\int f^+ dm \leq \int |f|dm < \infty\]and \[\int f^{-1} dm \leq \int |f| dm < \infty\]So this is precisely the definition of \(L^1\), its integral is finite and well-defined. i.e. if a function is Lebesgue integrable, it is thus an element of \(L^1\) (I will occasionally drop the argument for \(L^1\)).

This can be generalized \[L^p((X, \mathcal M, m)) := \{f: (X,\mathcal M, m)\rightarrow \overline{\mathbb R} : \int | f|^p dm < \infty\}\] which is called an \(L^p\) space.

CautionExample 6.12

\(\sin(x)/x \notin L^1\) since \(\int |\sin(x) /x| dx = \infty\) and thus \(\sin(x)/x\) is not Lebesgue integrable.

NoteDefinition 6.13 — Conditionally and Absolutely Convergent Series

Let \((a_n)_{n=1}^\infty\) be a sequence of real numbers.

The series \(\sum_{n=1}^\infty a_n\) is absolutely convergent if: \[\sum_{n=1}^\infty |a_n| < \infty\]

The series \(\sum_{n=1}^\infty a_n\) is conditionally convergent if it converges: \[\sum_{n=1}^\infty a_n = L \in \mathbb{R}\] but is not absolutely convergent: \[\sum_{n=1}^\infty |a_n| = \infty\]

A conditionally convergent series is fragile: by the Riemann rearrangement theorem, its terms can be rearranged to converge to any value we like, or to diverge (see the side topic in Lecture 10).

In measure theory, there is no natural analogue of conditional convergence as there is no natural ordering of the domain (sets have no natural ordering of elements, and so the integral is order-independent, which is why we do not encounter conditional convergence here). Remember that a measure must assigned a well-defined value to every measurable set, in particular, for a countable disjoint union, we have the criterion of countable additivity \[\mu(\bigcup A_n) = \sum \mu(A_n)\]where the LHS is order-invariant (the way we construct the union of sets does not matter), since the LHS is automatically order-invariant, and thus \[\mu(\bigcup A_{\sigma(n)}) = \sum \mu(A_{\sigma(n)})\]for some permutation \(\sigma\). But by the Riemann rearrangment theorem, a series that is invariant under all permutations holds iff it is absolutely convergent (this is just the contrapositive argument, if its invariant under all permutations, then it is not conditionally convergent, i.e. absolutely convergent). See this Stack Exchange discussion for more details.

Beyond nonnegative increasing sequences

The monotone convergence theorem (Theorem 6.5) only covers sequences that are nonnegative and increasing. It is natural to ask what happens in the other monotone cases.

Nonnegative and decreasing. Suppose \(f_1 \geq f_2 \geq \cdots \geq 0\) and \(f_n \to f\) pointwise. Then \(g_n := f_1 - f_n\) is nonnegative and increasing with \(g_n \to f_1 - f\), so the MCT gives \[\int (f_1 - f_n)\, dm \to \int (f_1 - f)\, dm.\] If \(\int f_1\, dm < \infty\), we may cancel \(\int f_1\, dm\) on both sides and conclude \(\int f_n\, dm \to \int f\, dm\). The finiteness assumption cannot be dropped: \(f_n = \mathbf 1_{[n,\infty)}\) is nonnegative, decreasing and converges pointwise to \(0\), yet \(\int f_n\, dm = \infty\) for every \(n\). On the other hand, \(f_n = \tfrac1n \mathbf 1_{[0,1]}\) satisfies the assumption, and indeed \(\int f_n\, dm = \tfrac1n \to 0 = \int 0\, dm\).

Increasing, but not necessarily nonnegative. Suppose \(f_1 \leq f_2 \leq \cdots\) and \(f_n \to f\) pointwise, and that there is a measurable \(g \geq 0\) with \(f_n \geq -g\) for all \(n\). Then \(h_n := f_n + g\) is nonnegative and increasing with \(h_n \to f + g\), so by the MCT \[\int f_n\, dm + \int g\, dm \to \int f\, dm + \int g\, dm.\] If \(\int g\, dm < \infty\), we conclude \(\int f_n\, dm \to \int f\, dm\).

Nonpositive and decreasing. If \(0 \geq f_1 \geq f_2 \geq \cdots\), then \(-f_n\) is nonnegative and increasing, so the MCT applies to \(-f_n\) directly and no extra assumption is needed.

In each case where extra work was needed, what rescued the argument was an integrable function controlling the sequence: \(f_1\) in the first case and \(g\) in the second. This suggests asking for such a bound directly: a single integrable \(g\) with \(|f_n| \leq g\) for all \(n\). With that bound in hand, monotonicity is no longer needed at all, and we obtain a convergence theorem for general sequences of functions, of any sign and with no monotonicity. This is the third and final convergence theorem.

ImportantTheorem 6.14 — Lebesgue Dominated Convergence theorem

Let \((f_n)\) be a sequence of functions in \(L^1\) which converges pointwise to a function \(f\). Assume there exists a \(g\in L^1\) such that \(\forall n\) we have \[|f_n|\leq g\] Then \(f\in L^1\) and \[\int f\, dm = \lim_{n\rightarrow \infty} \int f_n\, dm\]

In other words, if a sequence converges pointwise and is dominated by a single integrable function \(g\), called the integrable majorant, then the limit is integrable and we may pass the limit inside the integral. The LDCT makes no assumption about the sign or monotonicity of the \(f_n\). For the nonnegative decreasing sequences above, \(g = f_1\) is such a majorant, and requiring it to be integrable is exactly the assumption \(\int f_1\, dm < \infty\) that we needed there.
