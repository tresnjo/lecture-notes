13  Hardy–Littlewood Maximal Function and the Maximal Theorem

In what follows, we will denote \(B(x,r)\) the open ball centered at \(x\) with radius \(r\).

NoteDefinition 13.1 — Locally integrable

A function \(f:\mathbb R^n \rightarrow \mathbb R\) is said to be locally integrable, or in \(L_\mathrm{loc}^1\), if \(f\) is integrable with respect to Lebesgue measure when restricted to any compact set. (or equivalently, if for every \(x\) there is an \(r > 0\) such that \(f\) is integrable on \(B(x,r)\) wrt to Lebesgue measure.)

For \(f\in L_\mathrm{loc}^1\), \(x\in \mathbb R^n\), and \(r > 0\) we define \[A_r f(x) = \frac{1}{m(B(x,r))} \int_{B(x,r)} f(y) dm(y)\]which is simply the average of \(f\) over the ball around \(x\) with radius \(r\). This can be seen interpreted as the mean value of \(f\) over the ball centered around \(x\) with radius \(r\).

Some additional remarks:

  1. If \(f\) is continuous at \(x\), it is easy to see that \[\lim_{r\rightarrow 0} A_r f(x) = f(x)\]
  2. This cannot occur for all \(f\) since if we modify it at a single point, it would fail there. Take for example \(\tilde f(x) =1\) but \(\tilde f(y) = 0, y \neq x\), then the limit becomes \(0\) as \(r\rightarrow 0\) whereas the LHS is \(1\).
NoteDefinition 13.2 — Hardy-Littlewood Maximal function

If \(f\in L^1_\mathrm{loc}(\mathbb R^n)\), then the Hardy-Littlewood maximal function \(Hf\) is defined by \[Hf(x) := \sup_{r> 0} A_r|f|(x)\]

This functions essentially computes the average over the absolute value of \(f\) over all radii, and picks the largest such average amongst those radii. It is therefore a “measure” of the local average of \(|f|\).

One can verify that \(Hf\) is a measurable function by noting \[(Hf)^{-1}(\alpha, \infty) =\bigcup_{r>0} (A_r|f|)^{-1}\{(\alpha, \infty)\}\]where \(A_rf\) is a continuous function for \(f\in L^1_\mathrm{loc}\), and thus we have preimages of open sets under continuous functions which are still open, and thus \((Hf)^{-1}(\alpha, \infty)\) is a union of open sets.

ImportantTheorem 13.3 — (Hardy-Littlewood Maximal Theorem)

If \(f\in L^1(\mathbb R^n)\), then \(\forall \alpha > 0\) we have \[m(\{x: Hf(x) > \alpha\}) \leq \frac{3^n}{\alpha} \int |f|dm(x)\]

NoteProof

Let \(E_\alpha = \{x: Hf(x) > \alpha\}\). For each \(x\in E_\alpha\) there exists \(r_x > 0\) so that \[A_{r_x}|f|(x) > \alpha\] by the definition of the supremum. With this, we can for each \(x\) have an associated open ball, and we may denote this collection of open balls as \(\mathcal C\). Given \(c < m(\bigcup_{x\in E_a} B(r, r_x))\), we can use the covering lemma from Lecture 12 to find \(x_1, ..., x_k\) in \(E_\alpha\) so that \(k\) balls \(\{B(x_i, r_{x_i})\}\) are disjoint and \[\frac{c}{3^n} \leq \sum_{i=1}^k m(B(x_i, r_{x_i}))\] However, by our choice of \(r_x\)’s, i.e. \(A_{r_{x_i}}|f|(x_i) > \alpha\), we have \[\frac{c}{3^n} \leq \sum_{i=1}^k m(B(x_i, r_{x_i})) \leq \sum_{i=1}^k \frac{1}{\alpha}\int_{B(x_i, r_{x_i})} |f|(x) dm(x) \leq \frac{1}{\alpha} \int |f|(x) dm(x)\]where the last inequality follows from the disjointness of the balls. Since this holds \(\forall c < m(E_\alpha)\), we also have \[m(E_\alpha) \leq \frac{3^n}{\alpha} \int |f|dm\] as desired. \(\square\)
