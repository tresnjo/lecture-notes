15  Functions of Bounded Variation, Absolute Continuity, and the FTC

NoteDefinition 15.1 — Total variation, bounded variation and unbounded variation

If \(f:[0,1]\rightarrow \mathbb R\) we define the total variation of \(f\) on \([a,b] \subseteq [a,b]\) to be \[TV_{[a,b]}(f) := \sup \{\sum_{i=1}^n |f(x_i) - f(x_{i-1}) \} : a = x_0 < x_1 < x_2 <...<x_n = b\}\] We say \(f\) is of bounded variation on \([a,b]\) if \(TV_{[a,b]}f < \infty\) and of unbounded variation otherwise.

ImportantTheorem 15.2 — \(f\) is of bounded variation iff

\(f\) is of bounded variation if and only if there exist increasing functions \(g,h\) so that \(f = g-h\)

There is a one-to-one correspondence between signed measures and right-continuous functions of bounded variation, which we discuss hereafter.

NoteDefinition 15.3 — Absolutely continuous function

\(f : [0,1] \rightarrow \mathbb{R}\) is absolutely continuous if for all \(\epsilon > 0\), there exists \(\delta > 0\) so that if \(0 \leq x_1 < y_1 < x_2 < y_2 < \ldots < x_n < y_n \leq 1\) and \[\sum_{i=1}^n (y_i - x_i) < \delta\], then \[\sum_{i=1}^n |f(y_i) - f(x_i)| < \epsilon\]

ImportantProposition 15.4 — Absolute continuity of a function

Let \(f\) be a nonnegative right-continuous increasing function on \([0,1]\) with \(f(0) = 0\). Then \(f\) is absolutely continuous if and only if \(\mu_f << m\) where \(m\) is the Lebesgue measure.

This is consistent with the result for Cantor ternary function (which is n.n. right continuous and increasing). The corresponding Cantor ternary measure (which again is a unique finite Borel measure) where \(\mu_C(C) = 1\) and \(m(C) = 0\) so clearly \(\mu_C\) is not absolutely continuous wrt to \(m\). By contrapositive, \(F_c\) is therefore not absolutely continuous.

ImportantProposition 15.5 — Absolute continuity implies bounded variation

If \(f:[0,1] \rightarrow \mathbb R\) is absolutely continuous, then it has bounded variation.

The fundamental theorem of calculus

If \(f:[0,1] \rightarrow \mathbb R\) is increasing, does \[\int_0^1 f'(x) dx = f(1) - f(0) ?\] Recall that an increasing function has a derivative a.e (Theorem 14.7).

CautionExample 15.6 — The FTC fails for the Cantor function

The Cantor ternary function \(F_C\) (Theorem 4.6) is increasing and continuous, with \(F_C(0) = 0\) and \(F_C(1) = 1\). By Corollary 4.7 (c), \(F_C' = 0\) almost everywhere: \(F_C\) is constant on each open interval removed in the construction of the Cantor set, and these intervals have total length \(1\). Hence \[\int_0^1 F_C'(x)\,dx = 0 < 1 = F_C(1) - F_C(0).\] So the answer to the question above is no in general: being increasing, and even continuous, is not enough, and the inequality in the next theorem can be strict. The missing ingredient is absolute continuity, see Theorem 15.8 (3): \(F_C\) is not absolutely continuous, since the Cantor measure \(\mu_C\) lives on the Cantor set, which has Lebesgue measure zero.

ImportantTheorem 15.7 — The fundamental theorem of calculus for monotone increasing functions

If \(f:[0,1]\rightarrow \mathbb R\) is monotone increasing, then \[\int_0^1 f'(x) dx \leq f(1) - f(0)\]

ImportantTheorem 15.8

Let \(f\) be a nonneg right-continuous monotone increasing function on \([0,1]\) with \(f(0) = 0\). Let \(\mu_f\) be the associated measure on \([0,1]\) and consider the Lebesgue decomposition \(\mu_f = \mu_s + \mu_{ac}\) with respect to Lebesgue measure. Then:

  1. The Radon-Nikodym derivative of \(\mu_{ac}\) with respect to Lebesgue measure is given by \(f'\).

  2. \(\mu_{ac}[0,1] = \int_0^1 f'(x)\, dx\).

  3. \(f\) is absolutely continuous if and only if \(\int_0^1 f'(x)\, dx = f(1) - f(0)\). (So the second FTC holds if and only if \(f\) is absolutely continuous.)

  4. \(\mu_f\) is singular if and only if \(f'(x) = 0\) a.e.

CautionExample 15.9 — A singular measure

By Theorem 15.8, we have that \(\mu_C\) is singular iff \(F'_C(x) = 0\) lebesgue a.e., which we know is true. So the Cantor measure is a singular measure.
